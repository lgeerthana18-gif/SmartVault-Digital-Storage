SMARTVAULT — UPDATED DEMO
1. Extract the ZIP file.
2. Open the SmartVault_Updated folder in VS Code.
3. Open index.html in Chrome or Edge, preferably using VS Code Live Server.
4. First visit: enter your name and create a password. Later visits: enter the password and choose Show/Hide to view it while typing.
5. Use the dashboard categories: Photos & Videos, Documents, Mini Apps, Saved Links and My Files.
6. Choose Upload files, select one or more files, enter a display name and save. Auto Detect sorts common image, video and document file types.
7. Open, download, rename, delete or restore saved files. Photos and videos appear in their separate sections and in My Gallery / Video Player.
8. Mini Apps included: Calculator, Notes, To-do List, Calendar, My Gallery and Video Player. They open and run inside the website.

IMPORTANT LIMITATIONS
- This is a front-end demo. Files and settings are stored locally in the current browser on this device using IndexedDB/localStorage. They do not sync to another phone/computer and may be lost if browser site data is cleared. Keep backups.
- The sign-in screen is a simple local demo lock, not secure account authentication or encryption. The password is stored in this browser. Do not use a sensitive/reused password.
- A website cannot install arbitrary Play Store Android apps. The included Mini Apps are web tools that run inside SmartVault. Saved links open websites; they do not automatically install apps or download social-media videos.
- For real multi-device cloud storage, secure user accounts and app installation, a backend/cloud service and native app or PWA setup are required.
