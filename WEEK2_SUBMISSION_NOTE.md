# Week 2 Submission Note

**Project:** SmartVault — Front-End Application Development

This ZIP contains the HTML, CSS, and JavaScript source files for the SmartVault front-end prototype. The application includes connected sign-in, dashboard, file-library, media, documents, music, saved-links, and mini-app views. It demonstrates browser-side interactions for uploading and organizing files, previewing supported formats, downloading, renaming, deleting, restoring, and saving website links.

**Run:** Extract the ZIP and open `SmartVault_Updated/index.html` in Chrome or Edge. For the recommended development workflow, open the folder in VS Code and use Live Server.

Read `README.md` for the feature list, run instructions, testing checklist, and current prototype limitations.
