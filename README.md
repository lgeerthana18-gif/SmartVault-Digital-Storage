
# SmartVault – Digital Storage

## Project Overview
SmartVault is a digital storage web application designed to help users store and manage their important digital files in one place.

## Project Objective
The main objective of SmartVault is to provide users with a simple and convenient way to save, organize, access, download and restore their important files whenever needed.

## Key Features
- User Login and Registration
- Attractive Dashboard
- Photo Storage
- Document Storage
- Video and Music Storage
- Saved Links
- Custom File Naming
- Upload and Download Options
- View and Manage Stored Files
- Restore Files When Needed

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser Storage

## Project Modules
1. Login Page
2. Dashboard
3. Photos
4. Documents
5. Apps
6. Saved Links
7. File Upload and Download

## Project Purpose
SmartVault aims to make digital file management easier by providing a single platform to organize and access important files.
